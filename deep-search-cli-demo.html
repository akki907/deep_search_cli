The product · 02

Architecture · 03

The ReAct loop

One graph. Two core nodes. A controlled loop from reasoning to action and back.

01 / INPUTUserNatural-language question enters the session.
02 / THINKAgentQwen chooses a direct answer or a tool call.
03 / CHECKApprovalHuman confirms a tool the first time it is used.
04 / ACTToolsThe selected function runs and returns an observation.
05 / LOOPAnswerThe agent synthesizes the result and finishes.
Design principle: keep the model flexible, keep side effects visible, and keep the human in control of tool execution.

Human in the loop · 06

Approve once.
Keep moving.

An approval is remembered by tool name for the rest of the interactive process.

approval flow
you > What is 2 + 2?
Tool Call Request: calculator({ expression: '2 + 2' })
Approve? [A]pprove, [E]dit, [C]ancel: a
The answer to 2 + 2 is 4.

you > What is 3 + 3?
calculator request approved from session memory
The answer to 3 + 3 is 6.
∞

Safe by default

New tools still require a decision. Approved tools do not interrupt repeated work.

Edited calls and cancellations remain one-off decisions. Restarting the CLI clears the memory.
